# PL9 Local API — первый слой

Локальная REST-обёртка для установленной Parashara's Light 9. Сам движок PL9 не копируется в репозиторий. API не выполняет астрологические расчёты самостоятельно и не подменяет PL9 другим движком.

## Что есть в версии 0.1

- POST /horoscope принимает данные рождения в JSON по LOKPA-подобной схеме.
- Создаёт нативный файл карты BirthData XML.
- Пытается открыть XML в установленной PL9 через штатное меню File → Open.
- POST /exports/birth-data/run отправляет штатную команду Research → Export Birth Chart и ждёт изменения birthdat.txt.
- GET /exports/birth-data возвращает фактический экспорт PL9 в JSON.
- GET /exports/ephemeris читает Export/ephemeris.txt, если он уже создан в PL9.
- GET /health и /status показывают наличие EXE и процесса.

Если открытие или экспорт не подтверждены, API возвращает соответствующий статус, а не выдуманные расчётные данные.

## Что установлено по формату PL9

В архиве обнаружен нативный формат BirthData XML. Руководство описывает XML как редактируемый формат карты.

- BirthDate — Julian Day местного гражданского времени; часовой пояс и DST хранятся отдельно.
- В PL9 восточная долгота и восточное смещение часового пояса записываются отрицательными числами.
- В комплекте PL9 пример birthdat.txt разделён табуляцией и содержит 33 поля, хотя руководство называет формат CSV.
- Нумерация вспомогательных точек в руководстве противоречива. Поля 23–29 сохраняются как исходный массив без выдуманных названий.
- BDLoopUpMode — нативное поле XML. Значения A, D, S встречаются в файлах комплекта; по умолчанию передаётся D. Семантика этих кодов отдельно не установлена.

## Установка на Windows 10/11

Требуются установленная PL9 и Python 3.10+.

1. Откройте PowerShell в папке pl9-api.
2. Установите зависимость: py -3 -m pip install -r requirements.txt
3. При необходимости укажите путь к программе: $env:PL9_EXE = 'C:\GeoVision\PL9\PL9.exe'
4. Запустите: py -3 .\pl9_api.py

Либо запустите run.ps1 и передайте путь через параметр PL9Exe.

Сервер слушает только 127.0.0.1:10810. При старте генерируется API-ключ и один раз выводится в консоль. Для постоянного ключа заранее задайте переменную PL9_API_KEY. Передавайте ключ в заголовке X-API-Key.

Каталоги можно задать переменными PL9_CHARTS_DIR и PL9_EXPORT_DIR.

## Пример запроса

PowerShell:

~~~
$key = 'КЛЮЧ_ИЗ_КОНСОЛИ'
$body = @{
  birth = @{
    name = 'Example Native'
    gender = 'male'
    date = '2000-01-01'
    time = '12:00:00'
    utc_offset_hours = 0
    dst_hours = 0
    longitude_east_deg = 0
    latitude_north_deg = 0
    city = 'Test City'
    state = 'Test Region'
    country = 'Test Country'
    anka = 1
    rodden_rating = 0
  }
  open = $true
} | ConvertTo-Json -Depth 6

Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:10810/horoscope' -Headers @{ 'X-API-Key' = $key } -ContentType 'application/json' -Body $body
~~~

Координаты передаются в обычных знаках: восточная долгота положительная, северная широта положительная, UTC+5 — как 5. API преобразует их в знаки PL9. Дата и время — местные.

## Эндпоинты

| Метод | Назначение |
|---|---|
| GET /health, GET /status | Состояние API и процесса PL9 |
| GET /version | Версия обёртки |
| POST /horoscope | Создать XML и запросить открытие карты |
| POST /charts | Алиас POST /horoscope |
| GET /charts/{id} | Проверить наличие XML |
| POST /charts/{id}/open | Повторно открыть карту |
| POST /exports/birth-data/run | Запросить штатный экспорт PL9 |
| GET /exports/birth-data | Получить последний экспорт |
| GET /exports/ephemeris | Прочитать экспорт эфемерид |

OpenAPI-контракт — в openapi.yaml.

## Что пока не включено

Нет /check-promise, /dasha и /transits: эквивалентные автоматизированные вызовы PL9 ещё не подтверждены. KP Promise LOKPA нельзя подменять обычным KP-отчётом PL9.

## Проверки

Контрактные тесты запускаются командой py -3 -m unittest -v. Они проверяют XML, Julian Day, знаки координат, валидацию, HTTP API, авторизацию и разбор экспортного файла.

**Не испытано на Windows с реально установленной PL9:** открытие созданного XML, выполнение меню экспорта и сверка полученных положений с экранными таблицами. Это следующий интеграционный тест. До него нельзя объявлять расчётный интерфейс полностью рабочим.

## Безопасность

- Только loopback 127.0.0.1; внешний доступ не включён.
- Все запросы требуют X-API-Key.
- Тела запросов и данные рождения не пишутся в консоль.
- Не публикуйте ключ и не выставляйте порт в Интернет.
- EXE, DLL, эфемериды и личные карты в этот репозиторий не добавляются.
